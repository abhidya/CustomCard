# Manual Visual Grade: SDXL Turbo CFG 1.5 With Safe Fields

- Score: 65/100
- Status: blocked
- Production recommendation: do not promote yet
- Contact sheet: [open](./contact-sheet.png)

This is the best production-text candidate in the current local set. The
deterministic Comfy safe-field backgrounds make exact text readable and prove
that the compositor can neutralize busy artwork inside Comfy.

It is still blocked for production polish: the safe fields are blunt rectangles,
the surrounding art is too dense, and the back panel is too busy. The next
iteration should keep safe fields but improve their shape/padding and use a
flatter stationery workflow/checkpoint.
